# Test colour profiles

`CGATS001Compat-v2-micro.icc` is a compact CMYK output profile (a stand-in for CGATS TR 001 /
SWOP) from <https://github.com/saucecontrol/Compact-ICC-Profiles>, released under CC0 1.0
(public domain). It is used to test output intents and PDF/X-4; it is not bundled with the
library.
